# 2026 Software Development: Programming and Alogirthms (SDPA) MSc Course

In this repository I maintain additional materials I create for Lectures and Tutorials as part of the MSc SDPA Unit at the University of Bristol.

`lecture_code` contains scripts and Notebooks developed during lectures
`faqs` contains Notebooks addressing common questions
`additional_materials` contains extra materials - code, notebooks etc. developed to complement lectures and tutorials

## Published lecture resources

- [AI-assisted programming: slides, PDFs, references and examples](https://josephpb.github.io/2026-sdpa/lecture_code/ai_coding/)

The shared GitHub Pages workflow rebuilds these resources from `lecture_code/ai_coding` on relevant pushes to `main`. Local backups and speaker notes are excluded from the published site.
